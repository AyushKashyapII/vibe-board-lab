Live Mood Board 🎨

A real-time collaborative mood board UI where users can drag and drop sticky notes and images. This project is a UI-only MVP, designed to demonstrate a modern, interactive layout with light/dark mode, drag-resize functionality, and smooth animations.

🌟 Features

Landing Page: Choose to create or join a board.

Board Page:

Add and edit sticky notes

Add image placeholders

Drag & resize items freely

Smooth fade-in animations

Light/Dark Mode toggle

Responsive UI for desktop and mobile

Component-based design for easy future expansion
